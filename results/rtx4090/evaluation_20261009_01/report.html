读图说明 · B、L、任务与计时范围
B / batch
一次模型调用并排处理的输入数。B4 forward 是真批次；逐个生成四次仍是 B1。DMS 按 masked context 计数，不按变体数。
L / length
每条蛋白的残基数。ESM3 forward 加 BOS/EOS：L256 的 token 宽度为 258；变长 B4 padding 到 max(L)+2=854。padding 不计作有效残基。
forward
输出 logits / embeddings；不是生成序列。
生成任务
sequence 补序列；structure 产坐标；inverse 以坐标为条件补序列。sequence / inverse 遮住 4、5、13 位，生成 3 步；structure 生成 8 步；温度 0.7。
核心 / 标准计时
预热 3 / 正式 20；CPU 正式 3。DMS 每 assay 预热 1 次完整 sweep / 正式 3 次。
计时范围
benchmark 是正式稳态调用；hot delivery 包括准备与 CPU / PDB 交付；Systems pipeline 在新进程捕获加载到交付，含插桩开销，不代表磁盘冷缓存，也不替代 benchmark。
